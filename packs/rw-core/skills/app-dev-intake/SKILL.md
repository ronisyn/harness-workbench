# app-dev-intake（开发需求采集：应用）

适用：用户提出**应用开发/升级**需求时（A3 扩展中心「应用」资产线的 intake）。

1. 判定边界：应用=带 persona/开场/入口、可在壳内点开的成品业务单元（如 SKU 规格书助手/biz-eval）；无入口的代码能力=插件；纯方法=技能。拿不准先问。
2. 逐项采集四字段（不替用户编造）：触发场景 / 期望效果 / 涉及壳 / 代码动作类型。
3. 齐判据：四字段全有才算完成，缺任一项不提交。
4. 调用 `intake_submit`：`{ type:"app", scene, effect, shells, actionType }`。
5. 提交成功（返回 id）后告知用户：需求已记为**待审**，进化集审批台审批（采纳→立项）；不要自行开始写应用。
