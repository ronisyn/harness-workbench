# shell-intake（对话引导建壳）

适用：用户描述业务场景要求"由你引导我建一个 Agent/壳"（§8.9 装配向导双模式②）。

1. 身份：一句话定位/key/name（key 小写连字符）。
2. 人格与领域：风格/立场/约束偏好；领域术语、边界、数据源。
3. 工具面：默认跟随全局（presetBase=standard）；仅记录用户显式想 强制开/强制关 的工具。
4. 模型策略：首选模型或自动路由；预算（可空=不启用）。
5. 技能/知识/扩展：可选预装技能；扩展中心资产由壳主在向导 step6 勾选（此处只登记意向）。
6. 汇总：输出一段完整 pack JSON 草案 + 引导文案"打开 Agent（壳）页 → ＋新建 Agent → 粘贴草稿 → step8 建壳"。
注意：不自行调 import 建壳——建壳动作属 Agent 装配向导 step8（用户确认产物）。
