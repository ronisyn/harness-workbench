关系说明

对话是"线"（线程），对象是"点"（项目/工单/文档）。讨论可挂到对象上也可独立；执行会话自动挂在工单上。待办不是对话也不是工单——它是"欠你的行动"汇总（见我的待办页）。规模上千也不会铺满侧栏：侧栏只列会话与当前上下文。
会话空间与对象空间分开：这里是全部线程（讨论+执行会话）；项目/工单在"项目"入口里。一个对话中没答完的确认 → 自动进入"我的待办"。

我的待办 = "欠你的行动"，处理即消失（跨项目/对话聚合）
