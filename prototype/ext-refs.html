OpenHands · Planning Agent

开源 agent（社区最大之一）内置"任务规划器"：长任务由 Agent 自己维护一份 TODO.md，边干边勾；右侧面板实时显示任务清单。
抄：TODO.md=文件即任务，Agent 自维护 抄：清单面板与对话并排 抄：勾选状态回写文件（和 hello 一致！）
💡 它对"对话=任务吗"的答案是：对话是载体，任务清单是对话里的一等公民——和我们 Model2（对话为中心+阶段标签）很接近。

MetaGPT · 多智能体软件公司

开源框架：把需求按"公司流水线"交给不同角色 Agent，每个角色输出标准文档，喂给下一角色。
抄：角色 = 固定 SOP + 标准产出物 抄：上游文档是下游的"契约" 抄：可映射成我们的窗格分包（管理层→各角色窗格）

SWE-bench 系 · Issue→PR 自驱闭环

学界/开源主流（SWE-agent、AutoCodeRover、OpenHands resolver）：给 Agent 一个真实 GitHub issue，它能自己读码→修改→跑测试当验收→提 PR。评测基准 SWE-bench 用真实 issue+测试打分。
抄：验收=测试门禁（我们的 Q3=A 得到业界背书） 抄：失败用例回灌继续修
