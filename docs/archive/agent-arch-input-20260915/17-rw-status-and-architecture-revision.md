## 1. RW 现状（关键事实摘录）

### 能干什么
- **工具 64 个**，分三档（基础 24 / 专业 33 / 高危 7），可裁剪、可拦截；另有 MCP 外部工具动态注册
- **权限四档**：只读 / 读写 / 需审批 / 完全；高危工具弹审批卡
- **记忆四层**（会话 / 长期 / 方法 / 任务现场），**但没有向量检索**（关键词 LIKE + 模型主动写）
- **对话界面是完整业务后台**：11 板块控制台（模型广场/工具集/技能库/知识库/进化集/Agent/扩展中心/任务/审计/设置）
- **平台能力**：模型接入 9 家厂商、壳（租户级 Agent）、扩展中心、定时任务、任务契约 + 无人值守驱动器（验收钩子）、审计（90 天归档）、进化集、用量三档计费、模型观测、金标冒烟、渠道

### 为什么贵（用户自己诊断，按影响排序）
1. **每轮全量重发整个上下文**（历史 + 固定注入）——结构性成本
2. **固定注入大**：系统提示几百行 + 技能全文（1.6 万字符）+ 知识 12 条 + 项目说明 1.6 万 + 快照 + 8 条 git
3. **工具结果大**：普通 4000 字符、子代理 12000 字符进上下文
4. **多轮循环 N 倍** + 额外 LLM 调用（标题、摘要、语义折叠）
5. **子代理各带完整系统提示**

已在做的省钱手段：缓存友好排布（DeepSeek 命中 0.086 vs 未命中 2.3 元/百万 token，差 27 倍）、两道压缩、工具结果裁剪、预算护栏、全程记账。

**一句话诊断（用户原话）："贵不是因为它乱花，而是因为每轮全量重发 + 固定注入大 + 工具结果大 + 多轮；没有'按需召回'（无向量检索、无分层记忆调度），所以省不到根上。"**

### 和 harness 比（用户自己结论）
| 维度 | 结论 |
|---|---|
| 可插拔架构 / 沙箱 / 组件化压缩 / 规模化编排 / 常驻终端 | **RW 缺**（这是"引擎该有的"） |
| 多租户账本 / 业务交付面 / 计费 / 审计 / 治理 | **RW 更强**（这是"平台该有的"） |

### 想突出在哪（用户判断）
**卖"能入驻、能算账、能验收的业务岗位"，不卖"最聪明的模型"。** 三个卖点：① 岗位化交付（入驻客户系统、有职责边界、有交接、有成绩单）② 数据型业务判断（备货量/广告 ROI/详情页/BOM/客服话术，多源结构化数据 + 反复算 + 结论可验收）③ 可控可审计可验收（预算护栏、审批卡、审计留痕、验收钩子）。

### 代码组织
**半分开。** 已分：模型接入、工具、子代理、MCP、壳与资产、执行与现场、知识、渠道。
**三处硬耦合**：① 系统提示把 RW 运行环境写死（/srv/harness-workbench 等）② HTTP 层与对话编排混在一个 2392 行文件 ③ 工具与资产是"代码静态数组 + DB 行"，不是"声明 + 装载"。

## 2. 由此提出的架构修正（✅ 三条均已确认）

### 修正 1：RW 是壳，不是引擎（✅ 已确认，措辞已定为"平台/agent"）

之前定的是"引擎可换、壳在 harness 之上扩展"（ADR-5）。RW 总结显示：**RW 已经是壳（平台），而且强在 harness 缺的那部分。**

> 已定：**平台 = Ronisyn（工作台）**；**agent = roni（自研）+ DS harness + codex harness（可插拔零件）**；**harness = 零件库**（把沙箱、压缩、spill、workflow 移植进 roni）。Claude 不用。正式边界见 [`19`](./19-platform-vs-agent-boundary.md)。

### 修正 2：混合部署现在就要做（✅ 已确认，已落档）

用户明确：客户的数据中台是独立项目、在客户自己的服务器上，要装"手脚"上去就必须混合部署。
→ 已执行：`14` 升级为"现在要做"、`11` Tier 1 ③ 标"✅ 已定"、`00` / `architecture` 同步。
→ 关键澄清：**数据不搬家**——数据留在客户数据中台，把"数据面"（agent 运行时 + 连接器 + 沙箱）装进客户内网就地读取，控制面留在服务商。

### 修正 3：RW 的三件改造（✅ 顺序已定：①→②→③）

1. **抽引擎边界**（解三处硬耦合）——"三个 agent 可插拔"的前提。已展开见 `18`
2. **移植 DS harness 零件**（工具声明化 / spill / 工具结果修剪 / 压缩组件化 / **fail-closed 探针**）——治"缺引擎硬实力"和"贵"。✅ **已收口**（`20` + `23`）
   > ⚠️ **Day 4 第 3 轮自审修正**：原文写的是"**沙箱 gVisor** 移植"，**这是错的**。
   > 实读 dsh 0.1.5-rc.2：harness 的沙箱是 **bwrap / Landlock / Seatbelt / Windows ACL（同世界约束）**，**不是 gVisor 那类内核级隔离**。
   > **所以沙箱是"接口借、实现自研"**，不在移植清单里（`15` §4、`20` §1.1）。
3. **补按需召回**（向量检索 + 分层记忆调度 + 大结果落盘）——治"贵"的根
