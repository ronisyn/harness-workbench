## 1. 每任务注入（必带，轻量）
- ENV_MAP（环境事实+行为准则引用，agent.js msgs[0]）
- 【运行时快照】（每轮：轮次/护栏现值/累计成本/会话属性/政策版本 rev；最新覆盖旧版）
- 目标/契约（ensureRun goal、driver 注入 goal+acceptance、resumeHint 现场）
- 会话目标/技能/知识条目（index.js 组装：goals active、conv_skills、knowledge 前 12 条且仅 status=active）
- 项目说明：projects/<project>/AGENTS.md 存在则注入（WS5c→P25/O-25 已实施并去掉 default 门：default 项目也可放 AGENTS.md，存在才注入）

## 2. 按需读取（查询类工具，用到才带）
- 技能：skills_list 查目录 → skill_load 全文注入本会话（持续生效）；内容存 skills/<名>/SKILL.md（运行时文件，gitignore）
- 知识：kb_search（knowledge 表：account 下 scope=global / 壳私有 shell / 本会话 conv——shell 语义见总方案 B §7.3；仅返回 status=active，superseded/obsolete 为历史不参与检索）
- 历史轨迹：messages/tool_calls/contract_events（db_query）；子代理全步骤 subagent_report
- 现场：agent_runs（resumeHint 已注入；要细节 db_query）

## 3. 沉淀回路（做完固化，不留对话里）
- 复盘：3 行快复盘每次；打回=完整复盘（docs/复盘模板.md）→ kb_add(title="打回复盘:…")（KPI3 度量）
- 方法→技能：skill_save（task-approach/explore-discipline/self-audit 等）
- 事实/偏好/约定→知识：kb_add（scope=global / shell / conv，壳私有见总方案 B §7.3）
- 规则级改进→回流（双落点，2026-09-10 治理）：内核规则→docs/平台开发全集清单-v1.md O 域台账；平台化改造共识→《RW-Agent 平台化改造总方案》（总方案 B，见其 §2 边界/§11.2）

## 4. 归档（旧内容不占道）
- 长会话：>40 条历史触发摘要（conv_summaries，index.js F8 懒生成已有）；跨 >48h resume 时摘要入首轮（WS5e）
- conv_summarize 工具：会话收尾显式归档（已注册可用）
- 自动触发：scheduler 扫 24h 无消息会话调用 conv_summarize（已实现：server/scheduler.js 每 10 分钟扫 24h 无消息且 >60 条且摘要落后的 web 会话，最多 3 个/轮）
