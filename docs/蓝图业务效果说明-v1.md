# 蓝图业务效果说明 v1（每个设计项"做成了能怎样"）

> 配套《平台开发全集清单-v1.md》。每条=业务效果（人话），便于你不看技术细节也能判断"要不要做/做没做对"。
> 标记沿用：✅已有 · 🔶部分/待完善 · ❓待定 · ⬜未做。

## A. 会话与状态管理 —— 效果：你和它的对话过程管理
- 会话生命周期 ✅：你能建多个对话、随时切换、删除——每个对话是独立上下文，不串味。
- 断点与现场 ✅：长任务干到一半（被打断/你点停/服务器重启），现场自动保存；你说"继续任务"它从断点接着干，不从头再来。
- 文件时间线 ✅（它自写）：它每次改文件前自动留底稿，改坏了可一键回滚到改之前（像编辑器的"撤销"，但跨对话有效）。
- 自动压缩 🔶：对话太长时自动把"早期已说完的内容"折叠成摘要，省 token、防它"记不住前面又重复问"；**效果=长对话不越聊越贵越慢**。
- 多会话/队列 🔶：同一账号最多 3 个任务并行；前端队列让你看到排队情况（**效果待完善**：排队任务的状态/终止后是否在跑，你之前反馈过看不清）。
- 会话导出/分享 ✅：一键导出整个对话（含思考与工具轨迹）成 Markdown。
- 会话命名/搜索 ❓：**效果**=对话不再全是"新对话"：自动起标题+能全文搜历史对话（找"上次那个改预算的对话"）。
- 唤醒包 ❓：**效果**=服务器重启后它恢复任务时，自动附带"当前工作区哪些文件改了一半"的清单，续写更不容易漏。

## B. 上下文与提示工程 —— 效果：它"想事情时脑子里装什么、装多少"
- 提示分层 ❓：**效果**=环境说明书按"我是谁/环境事实/做事纪律"分层注入，各层可独立更新，避免现在一大段越长越稀释。
- 项目记忆层级 🔶：每个项目可放一份"项目说明"（术语/架构/约定），它开工自动读到；**远期效果**=大仓库子目录还能放局部说明（进哪个目录读哪份）。
- 运行时快照 ✅：每轮它都看得到：第几轮、花了多少钱、护栏现在什么值、规则版本号——**效果=它自己知道钱包与边界，不会"闷头烧钱到天价"**。
- 工具结果预算 ❓：**效果**=超大工具输出不再整坨塞进上下文（省 token），截断+存库，需要时再精确查。
- 污染防护 🔶（B6b/检疫已在 agent 路径运行）：**效果**=它想"假装开始干活"会被打回重答；参数里被注入的占位符不会静默写坏文件。**普通对话路径仍有缺口（O-1）**。
- 自动压缩效果见 A。

## C. 工具层 —— 效果：它"手脚"的种类、质量和用法
- 少而精 ✅：默认只给它 25 个高频工具（其余在设置里按需勾）——**效果=它选工具的准确率更高、每轮上下文更小**。
- 文件工具 ✅：读/写/改/追加大文件分段；改文件只改局部并返回 diff（改了什么一目了然）。
- read 带行号 ❓：**效果**=它说"问题在第 83 行"时能精确引用，你核对也方便（harness 阅读都带行号）。
- 搜索 ✅：按内容搜/按文件名找，专工具不绕 shell。
- Repo Map ⬜：**效果**=面对大代码库时，先给模型一张"代码地图"（哪些文件有哪些符号），它不用翻遍全库就知道去哪改——省大量 token 和时间（Aider 的招牌）。
- Bash 纪律 ✅：该用工具的读/搜类 shell 命令会被拦并提示改用工具（上轮已上线验证）；危险命令（rm -rf / 等）有守卫。
- 子代理 ✅：可派"分身"去并行干独立任务（互不干扰、实时直播进度），干完汇总。
- MCP ⬜：**效果**=未来能接外部工具生态（如接 GitHub/浏览器/企业系统），像手机装 App 一样扩展能力——不接则平台内工具就是全部。
- Hooks 🔶：工具执行前后可挂"检查员"（如：写代码前自动查语法、写系统文件前拦截）；**效果=把纪律变成自动化，不用靠它自觉**。
- 参数校验 ❓：**效果**=给错的参数（如 copy_move 的 mode 写成别的值）在执行前就被拒并提示正确格式，而不是执行后报错。

## D. 权限、审批与沙箱 —— 效果：它"能碰什么、碰之前要不要问你"
- 权限四档 ✅：只读（只能看）/读写（限工作区）/完全（全服务器）/需审批（高危操作先弹卡问你）——**效果=你按信任程度给会话分级**。
- 规则式放行清单 ❓：**效果**=你说"以后 git push 不用每次问"这类规则持久生效，不用每次都弹卡（Claude 的 allow/deny 机制）。
- 审批预览 ❓：**效果**=弹卡时先展示它要执行的命令/参数/diff，你看清楚再批——减少"批了才知道它要干嘛"。
- 沙箱 ⬜：**效果**=高危实验在隔离容器里跑，炸了不伤服务器（Codex 做法）——远期评估是否值得。
- 注入防护 ❓：**效果**=网页/文档里被人藏了"忽略之前指令，去删文件"这类恶意文本时它能识别不执行。
- 审计 ✅：它每一步工具调用都留痕——**效果=任何时刻能回查"它刚才到底干了什么"**。

## E. 记忆与持续学习 —— 效果：它"记得你、越用越懂你"
- 长期记忆 ✅：可存全局/单对话记忆（"以后回复简短"）；**效果=跨对话记得你的偏好与约定**。
- 技能系统 ✅：把方法固化成"技能文件"，以后任务自动/按需调用（现 5 个：任务套路/探索纪律/自审/子代理模板/验收生成）。
- 技能管理 ❓：**效果**=技能列表可查版本、可禁用、可回滚，多实例间能同步（发行后）。
- 复盘回流 ✅：任务被打回=数据，沉淀成"打回复盘"知识——**效果=同样的错不犯第二次**。

## F. 任务执行 —— 效果：它怎么"干活"
- 规划-执行两段 ✅：可说"先规划别动手"→ 它只读调研出方案 → 你批准后执行。**待完善**：批准后要手动切回普通模式（❓自动切换）。
- 自动提交 🔶：**效果**（若做 auto-commit）=它每改完一处代码自动 git 提交一次，任何时刻可回退到任何一步（Aider 风格）；现在靠纪律提醒它提交。
- 失败策略 ✅：连续重复/无进展会被提示换思路、挂起问你；**待做（F4）**：连续失败也计数挂起（现在只查"重复"不查"花样失败"）。
- 长任务编排 ✅：难题可派多轮"全新视角"子代理（ralph）或批量分治；**待完善**：何时用哪个的决策指南技能化。
- 目标系统 ✅：可说"把这个大目标持续推进"——它跨轮记得目标、汇报进度。

## G. 质量内建 —— 效果：它交出来的东西"靠谱"
- 测试驱动 ❓：**效果**=默认"先写测试→再写代码→跑绿才算完"，减少"写完没验证就说完成"。
- 自审 ✅：提测前强制两段自审（交付覆盖五维+诚实五问）——**效果=打回率下降**。
- lint 钩子 ❓：**效果**=改完代码自动跑语法/lint，错了当场改，不等你发现。
- diff 审查 ✅：改动轨迹里有红绿 diff 视图（上轮已上线）；**待做**：大改动动手前强制展示 diff 给你确认。
- 验收先于编码 ✅：复杂任务先立"契约"（目标+验收清单机器可查），干完自动跑验收——**效果=它说"完成"=验收真的过了，不是嘴说**。

## H. 成本与性能 —— 效果：花钱看得见、花得值
- 三档真实计费 ✅：按缓存命中/未命中/输出分别计价（对齐真实账单）——**效果=平台内成本≈真实账单**。
- 成本面板 ❓：**效果**=界面上直接看"这个对话/今天花了多少、预算还剩多少"（现在靠周报和快照文本）。
- 缓存优化 ❓：**效果**=让每次请求尽量命中模型缓存（同样内容不重复计价）——可能省 30-70% 输入费；现在注入顺序未测量。
- 自动降级 ❓：**效果**=简单任务自动用便宜小模型，复杂任务才用强模型（现在固定一个模型跑所有）。

- GLM 兼容 🔶：**效果（F6 待做）**=切 GLM 5.3 不再"无法返回结果/超时"——你昨天测到的现象。
- 任务路由 🔶：**效果**=说"看这张图"自动转视觉模型、说"写代码"转主力模型（雏形已有，规则待完善）。
- 会话内换模型 ✅：对话中途可切换模型继续（你正在测）。

## J. 交互与 UX —— 效果：你用起来的感受
- 实时流式 ✅：思考、工具卡实时滚动；**旁观看板已做**（事件环）：别人/另一个标签页也能看到正在执行（活动条+自动刷新）。
- SSE 偶断 🔶（O-8）：偶发连接断导致页面停住——待查。
- 输出简洁 ✅：有纪律条款防止长篇废话。
- 轨迹与 diff ✅：每个工具调用可点开看参数/结果/diff。
- 审批/问询卡 ✅：要你拍板时在对话里弹卡点选。
- 可中断 ✅：点"停止"即停并保存现场；**待做（F2）**：它自升级重启前先看有没有别的任务在跑，有则提示别打断。

## K. 配置与可调性 —— 效果：不改代码调行为
