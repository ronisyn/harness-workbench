## 3. 服务器化二次开发适配要点（本地工具→服务器差异）
1. 无人工点击：一切工具面事件走 SSE 卡片（approval/ask）+ REST 裁决
2. 路径模型：多用户/会话权限 → read/write 限工作区、full/guard 全量；本轮统一边界在 execTool 中央执行
3. 配置与密钥：DB settings 表 + 服务器目录 env（不入库不入 git）
4. 生命周期：systemd 自启、端口/ufw、reload_platform 自动重启、agent_runs 断点
5. 网络/模型：DeepSeek 直连、SearXNG 本地、OpenAI 兼容网关（超时/重试/空闲护栏）
